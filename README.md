# Bounded Responsiveness Scheduler (BRS)

Artifact repository for the paper *"Practical Bounded Responsiveness
Scheduling for Low-Latency Mobile Systems"*, accepted to the
**IEEE Transactions on Mobile Computing (TMC)**, 2026
(manuscript ID: TMC-2026-01-0047).

## Repository layout

| Folder    | Description                                                                                     |
| --------- | ----------------------------------------------------------------------------------------------- |
| `paper/`  | Final camera-ready paper (PDF) and the LaTeX source archive of the TMC manuscript.              |
| `code/`   | BRS implementation: Linux kernel patches, the scheduling simulator, benchmarks, tests, and CI.  |
| `ppt/`    | Presentation slides summarizing the BRS design and evaluation.                                  |

See `code/README.md` for build/run instructions and the citation entry.
